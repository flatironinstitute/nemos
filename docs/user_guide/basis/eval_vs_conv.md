# Basis Types: Eval vs Conv

Every basis comes in two classes. An `Eval` basis evaluates the basis functions on an input, to model a non-linear mapping from a task variable to the response; a `Conv` basis convolves the input with the basis functions, to model linear temporal effects such as spike history. See [Simple Basis Function](one_dimensional.md) for `Eval` bases and [Convolution](convolution.md) for `Conv` bases.
